# 2021-02-21 Readme

This file preserves the original board revision context for the QYT-8900D interface project.

Project revision date: 2021-02-21

Original hardware concept
- A simple breakout/interface board placed between the microphone and radio
- RJ-45 connectors used to simplify interconnect routing and field swapping
- Phone-plug jacks to allow insertion of a recording device or test audio source
- Passive, reversible wiring intended for experimentation and signal capture

This historical note is kept for traceability. The active project documentation has been updated to reflect the current direction of the work.
