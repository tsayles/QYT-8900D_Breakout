# QYT-8900D_Breakout

This project originally was intended as a simple breakout board inserted between a microphone and a radio. The goal was to provide a convenient way to connect and monitor the microphone path without permanently modifying the radio or mic wiring.

Original goals
- Build a small breakout adapter placed between the microphone and radio
- Add RJ-45 jacks to make the interconnects easier to route and swap
- Include phone plug connectors for temporarily inserting a recording device
- Provide a simple, reversible hardware interface for audio capture and troubleshooting
- Keep the design lightweight and easy to assemble for experimentation

This repository preserves that original concept as the historical starting point for the project.
